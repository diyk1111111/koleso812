# Колесо фортуны

Небольшое браузерное приложение на HTML, CSS и JavaScript. Добавляйте варианты, настраивайте их вес и запускайте колесо для случайного выбора.

## Возможности

- добавление и удаление секторов;
- настройка цвета и веса секторов;
- выбор с учетом весов;
- история результатов и статистика;
- сохранение в браузере;
- настройка удаления выбранного сектора после вращения.

## Запуск локально

Для ES-модулей нужен локальный веб-сервер. Если установлен Node.js, выполните `npm start` в папке проекта и откройте адрес, показанный сервером. Можно использовать любой статический сервер.

## Публикация через GitHub Pages

Сайт статический: сборка и установка зависимостей не нужны. В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**. После публикации адрес появится на странице Pages.

## Структура

- `index.html` — разметка;
- `style.css` — оформление;
- `js/` — логика приложения;
- `tests/` — тесты.
